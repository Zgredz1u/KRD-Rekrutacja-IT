Metody dostępne w API


1. GetTopDebts

Opis Zwraca TOP10 wierzytelności w bazie
URL https://rekrutacja-webhosting-it.krd.pl/api/Recruitment/GetTopDebts
Typ GET
Zwracana odpowiedź Status: 200
Dane: tablica wierzytelności (encja Debt)

2. GetFilteredDebts

Opis Zwraca wierzytelności, które spełniają kryteria wyszukiwania (NIP, numer sprawy lub nazwa dłużnika zawiera podany ciąg)
URL https://rekrutacja-webhosting-it.krd.pl/api/Recruitment/GetFilteredDebts
Typ POST
Parametry wejściowe obiekt {phrase: "poszukiwana fraza"} w formacie JSON
Content-type application/json
Zwracana odpowiedź W przypadku podania ciągu krótszego niż 3 znaki:
Status: 405
Dane: brak

W przypadku podania ciągu o długości co najmniej 3 znaków:
Status: 200
Dane: tablica wierzytelności (encja Debt) spełniających kryteria wyszukiwania

3. GetDebtsCount

Opis Zwraca liczbę wszystkich wierzytelności w bazie
URL https://rekrutacja-webhosting-it.krd.pl/api/Recruitment/GetDebtsCount
Typ GET
Zwracana odpowiedź Status: 200
Dane: liczba spraw (number)



Encja wierzytelności (Debt)


  • Id
    Opis: unikalny identyfikator techniczny (nieprezentowany na UI)
    Typ: number
  • Name
    Opis: nazwa dłużnika
    Typ: string (max. 64 znaki)
  • NIP
    Opis: numer identyfikacyjny podatkowej dłużnika
    Typ: string (max. 10 znaków)
  • Date
    Opis: data dodania zobowiązania
    Typ: data (format ISO 8601)
  • Value
    Opis: wysokość zadłużenia
    Typ: number
  • Address
    Opis: adres zamieszkania dłużnika
    Typ: string (max. 256 znaków)
  • DocumentType
    Opis: typ dokumentu stanowiący podstawę prawną
    Typ: string (max. 16 znaków)
  • Price
    Opis: ofertowa cena wykupu wierzytelności
    Typ: number
  • Number
    Opis: numer sprawy (biznesowy identyfikator wierzytelności)
    Typ: string (max. 32 znaki)
